# Dyson Control 0.1.10 候选版

供用户在自己的 Windows 主机上搭建和管理戴森球计划 Nebula 服务器。此版本仍为候选版；本地打包与 CI 产物不表示已公开发布。

## 使用流程

- 在浏览器中完成 SteamCMD 准备、Steam 授权与空目录首装；也可预览并接入已有的停服实例。
- 启动、保存、停止和重启游戏，加载已有存档；替换前自动保护完整的 `.dsv`、同名 `.server` 与已有 `.moddsv` 文件组。
- 导入、下载和恢复存档备份，断线后查回原上传任务；按类型与状态查找操作记录。
- 登录过期后清除未确认的操作，重新登录时读取当前状态；旧请求的延迟响应不会再次退出新会话，已提交操作的回执仍可核对。
- 管理游戏与模组版本、依赖、锁定和配置历史；导出匹配的 r2modman 配置包，并校验玩家手中的副本。
- 查看在线玩家、进出历史、日志、资源指标和 UPS/TPS；提供定时备份与有次数上限的崩溃恢复。
- 安装、升级时预先验证 SQLite 和 Windows 原生授权控制台。升级失败自动恢复原任务与版本，卸载保留游戏、配置和存档。
- 初始化私有配置时可直接指定信任的面板更新仓库，随后在“版本”页检查公开正式版本。

## 选择下载包

| 文件 | 用途 |
| --- | --- |
| `dyson-control-v0.1.10-windows.zip` | 完整包，含匹配的 Bridge；用于新装或接入已有游戏 |
| `dyson-control-v0.1.10-windows-panel-only.zip` | 仅面板包，用于已有部署的面板更新，不含 Bridge |
| 同名 `.sha256`、`SHA256SUMS` | ZIP 完整性校验 |
| `release-evidence.json` | 两个候选包的源码提交、大小、SHA-256 和 Bridge 构建身份 |

安装步骤见包内 `docs/installation.md`。先核对 ZIP 校验值，再解压；初始化私有配置并安装面板，随后在“安装与授权”中准备游戏。已有面板升级使用新包的 `upgrade-control.ps1`，或通过面板更新页发现已正式发布的仅面板包。

## 运行条件与已知限制

- Windows 10 1809 / Windows Server 2019 或更新版本，Node.js 24+，Windows PowerShell 5.1；注册任务需管理员权限，安装生产依赖需联网。
- 需要拥有游戏的 Steam 账号。游戏用户仍须保持 Windows 登录，并打开已登录的桌面 Steam；尚不承诺重启后无需登录即可恢复游戏。
- 已测游戏 `0.10.35.29151` / Nebula `0.9.24.2` 在无人时仍可能停止世界 tick。不要依赖当前版本保证空服工厂持续生产。
- 单客户端轻载测试不能代表多人、大型工厂或所有可选模组的性能与兼容性。
- 管理入口默认仅本机可用。部署者配置自己的 HTTPS 管理入口与 Nebula 游戏地址，并在自己的网络上验证实际入服。

真实游戏和客户端流程的验证边界见 README 与 `docs/acceptance.md`。本版本不捆绑游戏或第三方模组程序集。
