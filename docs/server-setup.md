# 安装与 Steam 授权

登录管理员后，打开“安装与授权”。现有服务器可以只修复 SteamCMD 登录；首次开服可以在配置指定的空游戏目录中安装官方游戏、Nebula、BepInEx、依赖和匹配的 Bridge。

## Steam 授权

1. SteamCMD 不存在时，点击“准备 SteamCMD”。面板从 Valve 的固定 HTTPS 地址下载客户端，在独立目录初始化后移入目标位置。已有目录包含其他文件时会停止，不会覆盖。
2. 填写 Steam 账号，点击“登录 / 验证授权”。已有配置的账号固定使用该账号；新安装只保存账号名，默认客户端位置为 `dataDirectory/steamcmd/steamcmd.exe`。
3. 页面要求时输入密码、Steam Guard 验证码，或在 Steam 手机应用中批准登录。未收到对应提示时不会显示输入框。
4. 登录进程退出后，面板用相同运行身份再次仅传入账号名，查询 `app_info_print 1366540`。只有缓存授权可复用并取得 public build，页面才显示授权可用。

凭据输入只接受 HTTPS 或服务器本机访问。密码和验证码经过受管理员登录、同源校验及会话绑定保护的专用接口，通过私有子进程进入 SteamCMD 的 Windows 伪控制台；不会写入命令参数、环境变量、配置、任务数据库、面板日志或终端回显接口。页面没有通用终端功能。SteamCMD 自己保存的会话缓存应位于受保护的服务器目录。

Windows 交互登录使用 Microsoft `node-pty` 的 ConPTY 支持，依赖固定版本随锁文件安装，提供 Windows x64 / ARM64 预编译模块；需要 Windows 10 1809 或更高版本。首次 SteamCMD 自更新明确完成并返回状态 7 时，会再运行一次 `+quit` 验证客户端；其他失败不会自动重试。

授权默认十分钟超时；取消、退出管理员登录、会话失效或面板关闭都会停止本次进程。重复输入旧提示、其他管理会话提交、换行和控制字符均被拒绝。授权、版本查询、游戏安装共用 SteamCMD 进程锁。密码或 Steam Guard 变更、撤销设备后，可能需要重新授权。

“验证授权”只进行登录及在线版本查询，不更新或启动游戏。

## 首次安装

先按 [Windows 安装说明](installation.md) 安装完整面板包并准备配置。游戏目录必须与面板数据、存档、备份、Bridge 通信和 SteamCMD 目录分开。目标已有任何文件或已有同名游戏任务时，首次安装会拒绝执行；现有服务器仍使用日常管理和更新操作。

服务器上需要一个已启用的本地 Windows 用户。该用户必须保持交互登录并运行拥有戴森球计划的桌面 Steam。SteamCMD 的下载授权与游戏运行所需的桌面 Steam 会话分别检查。选择该用户后，完成 Steam 授权并点击“一键安装服务器”。

安装流程通过原有任务队列串行执行：

1. 验证空目录、启动任务不存在、游戏未运行及 Windows/Steam 用户条件。
2. 验证完整发布清单、面板版本、Bridge DLL 大小和 SHA-256、九项编译依赖。
3. 在游戏目录旁的独立暂存目录执行官方 `app_update 1366540 validate`。要求成功退出、明确安装确认、完整游戏清单和必要文件；拒绝链接、异常文件和超限内容。
4. 安装 Nebula、BepInEx 及解析后的依赖，核对九项实际程序集与 Bridge 编译依据的大小和哈希。任何不一致都会停止，目标游戏目录保持原样。
5. 再次检查目录和任务，按配置创建尚不存在的存档、备份目录，保留其中已有内容；路径是文件或经过链接时停止。随后将准备好的文件移入空游戏目录，调用现有游戏配置脚本完成账户访问检查、Bridge 密钥保护和启动任务注册。首次安装以仅新建方式注册任务；检查后新出现的同名任务也不会被替换。
6. 确认启动任务存在且游戏未启动，记录安装完成，并清除旧面板数据中遗留的自动开服意图。前往概览后由管理员手动首次启动。安装失败或中断会暂停自动恢复，避免启动尚未确认的安装。

仅面板包不含 Bridge，因此只能准备或修复 Steam 授权。第一次安装服务器需要完整包；若最新 Steam 游戏或模组已经改变编译依赖，应先发布与它们匹配、通过验证的完整包。

新安装写入 `steam_appid.txt` 以及一次性的首次世界标记。首次启动时，有存档则加载最新存档；没有存档时使用 Nebula 的 `-newgame-default`。标记在启动前消费，之后即使目录再次变空也不会自动创建新世界。只有 `.server` / `.moddsv` 而没有 `.dsv` 时，会停止而不是创建世界。显式选择的存档优先。

首次启动失败且尚无存档时，标记保持已消费状态。需要检查失败原因后，由管理员显式恢复首次世界许可或导入完整存档，不能依赖自动重启另开世界。

## 失败与验收

失败的下载文件和 `dataDirectory/first-install/<id>/installation.json` 会保留。如果配置失败且确认没有启动任务或游戏进程，会把本次新安装目录移回暂存目录；不能确认任务清理成功时保留原目录并记录 `needs-review`。不会自动重试、覆盖已有游戏、迁移存档或启动服务器。

安装成功仅证明文件和启动配置就绪。首次实际启动、Bridge 联通、存档完整性及外部玩家加入仍需分别验收。防火墙、端口转发、外网地址和图形版 Steam 登录不会在安装时自动修改。

参考：[Valve SteamCMD](https://developer.valvesoftware.com/wiki/SteamCMD)、[Valve 账号授权说明](https://partner.steamgames.com/doc/sdk/uploading)、[Nebula 无界面服务器说明](https://github.com/NebulaModTeam/nebula/wiki/Setup-Headless-Server)。
